# PyAutoGUI
🚀 Automating with Python: My PyAutoGUI Learning Journey! 🖱️💻
I recently explored the power of PyAutoGUI, a Python module that lets you control the mouse, keyboard, and even recognize screen images.
As a hands-on project, I created an auto messaging script that: 
 ✅ Opens WhatsApp Web, clicks a contact
 ✅ Sends automated messages in a loop
 ✅ Uses sleep timers, keyboard actions, and position tracking for precise control 
💡 This automation journey helped me understand how GUI control works in real-time applications.
